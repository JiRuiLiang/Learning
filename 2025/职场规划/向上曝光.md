## 曝光路径
1. 信号模型
  - 能力信号
    + 业绩（目标管理）
    + 行业关注（对外输出）
    + 对个人的认证（证书）
  - 承诺信号
    + 稳定输出
    + 说到做到（大目标(吸引注意力)拆解小目标(完成)，做到了使劲说）
  - 文化信号
    + 价值观

2. 3D模型
  - Documentation(文档化) 沉淀日常工作
  - Discussion(讨论) 对文档的探讨
  - Demonstration(展示) 
    + 自媒体
    + AI智能体
    + 出版


3. MVP能力模型
  - Marketable 可市场化的
    + 有变现机会
    + 稀缺
  - Visible 可视化的
    + 即3D模型
  - Perceivable 可感知的
    + 用我和不用我感受是不一样的

30%超额原则，在自己业绩120%完成度的情况下，抽出30%的时间经营自己的曝光度
